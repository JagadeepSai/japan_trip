## How to add this in Wanderlog

### A · Create the trip
1. Open [wanderlog.com](https://wanderlog.com) → sign in.
2. **New trip** → dates **14–26 Oct 2026**.
3. Add destinations: Tokyo, Hakone, Kyoto, Osaka.

### B · Build each day
1. Open the trip → **Itinerary**.
2. For **Day 1**, tap **Add a place**.
3. Paste the **Paste list** for that day (one place per line).
4. Drag into order; add times from the notes.
5. Repeat for Days 2–13.

Paste **8–12 places at a time**. If a name fails, search the fallback in parentheses.

### C · Notes & bookings
1. On each place → add a **note** (times, tickets).
2. **Reservations** → flights + hotels.
3. Invite friends → **Share** → Editors.
